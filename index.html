Six layers between a request and a released action

One shared architecture runs under every system: orchestration, an ephemeral runtime, an interoperable transport fabric, zero-trust security, tracing with cost attribution, and governance with human approval.

1 · Swarm orchestration layer

LangGraph · Claude Agent SDK · OpenAI Agents SDK · Google ADK · CrewAI · AutoGen · Temporal (durable workflows) · XState

What this layer does
  • Supervisor, hierarchical and peer-swarm topologies; decomposition, hand-off, consensus; asynchronous event-driven orchestration, self-correcting retries.
  • Autonomy widened only behind evaluation gates and human-in-the-loop approval.

2 · Cognitive runtime & micro-harness layer

Python / FastAPI · Pydantic (structured output) · E2B / gVisor sandboxes · Docker · pgvector · Neo4j / NetworkX graph traversal · Redis · vLLM

What this layer does
  • Per-task runtimes synthesised at dispatch: prompts, tools, memory and policies compiled for one job, then discarded.
  • Sandboxed tools, scoped credentials, token and time budgets, structured-output contracts; multi-hop GraphRAG as a runtime service.

3 · Transport & interoperability fabric

MCP Python / TypeScript SDKs · A2A SDK · AP2 · Connect RPC / Protobuf · gRPC · OpenAPI · NATS / Kafka · Envoy / AgentGateway

What this layer does
  • MCP servers over stdio and Streamable HTTP (spec 2026-07-28, stateless, OAuth 2.1); A2A v1.0 Agent Cards over JSON-RPC, gRPC and HTTP+JSON for federated discovery.
  • AP2 mandates for agent payments; versioned contracts for schema evolution.

4 · Zero-trust & multi-tenant security plane

SPIFFE / SPIRE · OAuth 2.1 / OIDC (Keycloak) · Open Policy Agent · HashiCorp Vault · PostgreSQL RLS · Kubernetes NetworkPolicy · mTLS

What this layer does
  • Workload identity, least-privilege tool scopes, per-request authorisation (NIST SP 800-207); controls mapped to the OWASP LLM and Agentic Top 10 (2026).
  • Cross-silo tenant isolation: row-level security, separate keys, encrypted exports.

5 · Tracing, attestation & micro-FinOps

OpenTelemetry · LangSmith · Langfuse · Grafana / Prometheus · Sigstore-style signing · FOCUS 1.4 · OpenCost · Power BI

What this layer does
  • OpenTelemetry GenAI spans through MCP trace context; SHA-256 signed attestation of every tool call and model decision — a non-repudiable audit trail.
  • Token-level cost per tenant, agent and task; FOCUS-aligned data; cost per successful task as the KPI.

6 · Governance & HITL guardrails

LangGraph interrupts (HITL) · NeMo Guardrails · Guardrails AI · DeepEval / Ragas evaluation · GitHub Actions gated releases · Argo Rollouts

What this layer does
  • Human approval at the compilation layer for healthcare, SAP ERP and therapeutic EdTech; release gate = regression evaluation + output validation + rollback.
  • EU AI Act and ISO/IEC 42001 readiness (not certification).
